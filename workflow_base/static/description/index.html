Visual Workflow Builder for Odoo

Create and manage complex approval workflows with an intuitive drag-and-drop interface. No coding required to define stages, transitions, and approval rules.

Key Features

Visual Workflow Designer

Drag and drop interface to create workflow stages and define transitions between them. See your workflow as a visual flowchart.

Request Types

Define different workflow types for various business processes. Each type has its own stages and routes.

Stages & Routes

Configure workflow stages with colors, visibility settings, and readonly controls. Define routes with conditions and actions.

Access Control

Control who can move requests through specific routes using user groups and user-level permissions.

Server Actions

Trigger automated server actions when transitioning between stages. Send emails, update records, or run custom code.

Easy Integration

Simply inherit from request.request to add workflow capabilities to any Odoo model.

How It Works

  1. Create a Request Type - Go to Administration > Workflow Configuration > Request Types
  2. Design Your Workflow - Use the visual designer to create stages and connect them with routes
  3. Configure Stages - Set colors, readonly behavior, and visibility for each stage
  4. Define Routes - Set button styles, access rights, and optional server actions
  5. Inherit in Your Model - Add workflow capabilities with a simple Python inheritance

Quick Start Example

Add workflow capabilities to your custom model:

from odoo import models, fields

class MyRequest(models.Model):
    _name = 'my.request'
    _inherit = ['request.request', 'mail.thread']
    _description = 'My Custom Request'

    name = fields.Char(string='Name', required=True)
    description = fields.Text(string='Description')

    # The stage_id and type_id fields are inherited from request.request
